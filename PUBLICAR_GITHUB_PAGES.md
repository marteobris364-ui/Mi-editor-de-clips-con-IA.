# Publicar ClipMaker gratis con GitHub Pages (resumen)
1. Crear cuenta en GitHub.
2. Crear repositorio público nuevo, por ejemplo `clipmaker-mobile`.
3. Subir todos los archivos de esta carpeta (index.html, app.js, styles.css, manifest.json, sw.js).
4. En Settings → Pages, seleccionar deploy desde la rama principal y carpeta root.
5. Esperar URL `https://TU-USUARIO.github.io/clipmaker-mobile/`.
6. Abrir esa URL en Safari iPhone → Compartir → Añadir a pantalla de inicio.

No subas videos privados ni claves/API tokens al repositorio.
