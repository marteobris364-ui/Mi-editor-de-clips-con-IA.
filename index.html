Qué es y qué no es esta versión

Incluye: cortes por tiempo, lista editable, exportación MP4 vía FFmpeg WebAssembly, texto de títulos y archivo SRT estimado.

Aún no incluye IA semántica real: no comprende el diálogo, no garantiza viralidad, no elimina silencios automáticamente ni descarga contenido de plataformas protegidas. La exportación puede fallar con archivos grandes en iPhone.

Para una experiencia estable, publicar esta carpeta en un hosting HTTPS como GitHub Pages. El archivo local puede tener restricciones de Safari.
